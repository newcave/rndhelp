# RCMS 연구비 사용 등록 가이드 (통합RCMS, 연구개발기관 사용자)

이 문서는 RCMS 매뉴얼의 화면 설명을 원문 화면과 대조해 정리한 것이다.
출처: 「RCMS 초보자용 매뉴얼」 v1.0(2026.7.23), 「RCMS 연구개발기관 사용자 매뉴얼」 v1.6(2026.2.11), 「RCMS 숙련자용 매뉴얼」(2025.7.16) FAQ.
화면 이름·버튼 위치는 시스템 개편으로 바뀔 수 있으므로 실제 화면과 대조해 사용한다. 비목 판단·증빙 기준은 「연구개발비 사용 기준」(고시)이 우선한다.

## 연구비 사용 3단계 흐름
출처: 초보자용 매뉴얼 33·44·48쪽
1. 연구비 사용 등록: 연구개발비 사용 내역(증빙 정보, 비목 정보, 거래처·계좌 정보)을 RCMS에 보고하는 단계. 이체 실행 전 단계다.
2. 연구비 이체 실행: 등록한 건을 선택해 RCMS 금고은행 계좌의 연구개발비를 거래처 계좌 또는 기관 계좌(자계좌)로 실시간 이체한다.
3. 연구비 이체 결과 확인: 이체 상태(정상/오류)를 확인하고, 정상이면 이체확인증을 출력할 수 있으며 오류면 원인을 조치하고 재실행한다.
메뉴 경로: 연구비사용 → 연구비사용등록 / 연구비이체실행 / 연구비이체결과. 이체 완료 후 상세 내역은 연구비현황 → 연구비사용내역에서 조회한다.

## 등록 유형: 증빙 우선 등록과 비목 우선 등록
출처: 초보자용 매뉴얼 34~37쪽
- 연구비사용등록 화면 상단에서 과제를 선택하고 등록 유형 탭을 고른다: 증빙우선등록 / 비목우선등록 / 현물등록 / 인건비 직접지급 등록.
- 증빙 우선 등록: 증빙(전자세금계산서, 카드, 현금영수증, 기타) 1건을 먼저 고르고, 그 증빙에 해당하는 비목(항목·세부항목)을 여러 줄 등록한다. 예: 카드 1건에 식비·교통비 등.
- 비목 우선 등록: 비목(항목·세부항목) 1개를 먼저 고르고, 그 비목에 해당하는 증빙을 여러 건 등록한다.
- 인건비 직접지급과 현물은 각각 전용 탭을 쓴다.
- 과제 선택 후 화면 하단 노란 영역에 비목별 사용한도(예산·계획·집행·잔액)가 표시된다.
- 참고: 세부정보 동의(주관연구개발기관 협약정보 확인)의 '연구개발비 사용시작' 및 펌뱅킹 이용 등을 수정하지 않으면 연구비 사용이 불가할 수 있다.

## 사용 내역 입력란 (증빙 우선 등록 화면)
출처: 초보자용 매뉴얼 37·41쪽
- 증빙선택(필수): 증빙 유형을 선택한다.
- 항목(필수): 예) 연구활동비 / 세부항목(필수): 예) 회의비, 출장비 / 품목(필수): 사용 내용을 적는다.
- 사용금액, 공급금액(필수), 부가세액(필수): 공급금액과 부가세액을 구분해 입력한다.
- 이월금 사용여부, 재원별 사용금액(상세), 증빙자료첨부(등록하기), 인건비내역 등의 칸이 있다.
- '+추가'로 행을 늘려 여러 비목을 한 번에 등록할 수 있다.
- 거래처 및 계좌정보(필수) 버튼으로 거래처·계좌를 입력한 뒤 '등록'을 누른다. '임시저장'도 가능하다.

## 증빙 유형 4가지와 특징
출처: 초보자용 매뉴얼 36쪽
- 전자세금계산서·현금영수증: 국세청 홈택스로 발행된 내역만 사용 가능하며, 조회 시 법인범용공인인증서가 필요하다. 등록 후 거래처로 이체한다.
- (연구개발비) 카드: 카드 사용 후 RCMS에 사용내역을 등록하면 카드사별 결제일에 결제 대금이 지급된다. 결제일 전에 등록해야 결제일에 맞춰 대금이 지급된다.
- 기타: 전자 증빙이 원칙이며, 부득이하게 전자 증빙 등록이 어려운 경우(예: 인건비성 항목, 해외거래 등) 기타증빙으로 등록한다. 기타증빙은 거래처 정보를 직접 입력한다.

## 전자세금계산서 증빙 등록 방법
출처: 초보자용 매뉴얼 38쪽
1. 전자(세금)계산서 내역 조회 창에서 '기간 조회' 탭을 선택한다(승인번호를 알면 '승인번호 조회'로 인증서 없이 조회 가능).
2. 세금계산서(일반) 또는 계산서(면세)를 선택하고 기준일자를 입력해 조회한다. 조회 시 법인공동인증서로 인증한다.
3. 승인번호를 클릭하면 상세 정보를 볼 수 있다.
4. 공급금액만 사용 등록하려면 '부가세액을 제외한 공급금액만 등록합니다'를 체크한다.
5. 정보를 확인하고 '적용'을 누른다.

## 현금영수증 증빙 등록 방법
출처: 초보자용 매뉴얼 39쪽
1. 사용연월을 조건으로 '조회'하여 국세청 현금영수증 정보를 불러온다(법인공동인증서 인증 필요).
2. 내역을 확인하고 '적용'을 누른다.
참고: 현금영수증 지출증빙은 정오(12시) 이전에는 전산처리 일정상 전일 거래가 조회되지 않을 수 있다. 거래처에서 현금영수증을 먼저 발급받고 홈택스에서 조회되어야 등록할 수 있다.

## 카드 증빙 등록 방법
출처: 초보자용 매뉴얼 40쪽
1. 카드사용 내역 조회 창에서 RCMS에 등록된 카드를 선택한다.
2. 사용일자를 조건으로 조회한다.
3. 연구비로 사용 등록할 내역을 선택하고 '적용'을 누른다.
4. 부가세액 변경 여부를 확인하고 저장한다. 부가세 0% 또는 10%를 선택하거나 수정부가세액을 입력할 수 있다. 부가세 환급 대상 여부와 관계없이 공급금액과 부가세액은 구분해 등록해야 한다.
참고: 카드 사용내역은 RCMS에 카드 등록을 마친 다음 날부터 조회되며, 등록일부터 3개월 전까지의 승인내역이 조회된다. 사용 내역이 RCMS로 전송되기까지 2~4일 정도 걸린다. 승인 후 취소한 경우 취소 금액을 뺀 나머지만 등록할 수 있다.

## 거래처 및 계좌정보 입력
출처: 초보자용 매뉴얼 41쪽
1. 증빙 유형을 선택한다.
2. 항목, 세부항목, 품목을 입력하고 증빙파일을 등록한다.
3. '거래처 및 계좌정보'를 누른다. 전자세금계산서·카드·현금영수증은 저장한 증빙의 공급자 정보가 자동 입력되고, 기타 증빙은 직접 입력한다.
4. 거래처 정보를 확인한 뒤 사업자등록번호 '미확인' 버튼을 눌러 확인한다.
5. 전자세금계산서·현금영수증·기타 증빙은 '거래처계좌이체' 또는 '연구비(기관)계좌이체'를 선택해 입금처를 정한다. 카드 증빙은 기관의 카드결제계좌로 입금되므로 계좌정보 입력이 생략된다.
참고: 과세 연구개발기관 상호 간 현금거래나 휴폐업 거래처와의 거래는 불가하므로 사업자번호 유효성 확인 후 등록한다. 개인에게 지급해야 하는 예외 상황은 '개인거래'를 체크해 집행할 수 있으나 사유 소명자료를 추가로 올려야 하며 상시점검·정산 시 검토될 수 있다.
참고: 연구비(기관)계좌이체로 받은 뒤 거래처에 이체한 사실에 대한 증빙을 연구비(기관)계좌이체일부터 3주 이내에 등록하지 않으면 연구비 사용 등록이 제한될 수 있다.

## 부가정보 등록 (출장비·회의비·전문가활용비)
출처: 연구개발기관 사용자 매뉴얼 91~92쪽, 숙련자용 매뉴얼 FAQ Q20·Q21(96쪽)
- 2024년에 시작된 과제(연차)부터 국가연구개발정보 처리기준에 따라 연구활동비 중 출장비, 회의비, 외부 전문기술 활용비(전문가활용비) 집행 시 부가정보를 입력해야 한다.
- 등록 시점: 연구비 사용 등록 시(이체 전) 연구비사용 → 연구비사용등록에서, 또는 이체 후 연구비현황 → 연구비사용내역에서.
- 방법: 항목·세부항목(예: 연구활동비/회의비)을 선택 → 증빙자료 등록 → '부가정보 등록하기'를 눌러 입력 → 저장.
- 회의비: '회의비등록' 창의 '회의참여자 등록 목록'에 참여자를 등록한다. 참여연구자는 '참여연구자조회'로 불러오고, 외부 인력은 목록 오른쪽 '+추가' 버튼으로 인원 수만큼 행을 추가해 직접 입력한다.
- 출장비: 출장목적, 국내/해외 구분, 출장기간, 출발지, 도착지, 출장인력(기관명·참여자명·국가연구자번호)을 입력한다. 국가연구자번호는 선택 입력이다. 해외 학술행사 참석이면 학술행사 정보를 입력하고, 아니면 '해당없음(학술행사 관련 없음)'을 체크한다.
- '지난 부가정보 불러오기'로 이전 입력을 재사용할 수 있다.

## 등록 내역 수정·삭제와 증빙파일 수정
출처: 초보자용 매뉴얼 45~46·51쪽
- 이체 실행 전: 연구비이체실행 화면에서 대상을 조회해 '수정'(항목·세부항목·품목·공급금액·부가세액, 거래처·계좌정보 수정) 또는 '삭제'한다.
- 이체 완료 후 증빙파일: 연구비현황 → 연구비사용내역에서 '증빙파일수정'으로 조회·수정한다. 사용실적보고서 제출 전까지 가능하며, 제출 후에는 정산 인정구분이 '미확정' 또는 '보완요청'인 경우에만 수정할 수 있다.
- 수정 권한: 과제책임자, 이체 권한을 부여받은 사용자, 참여연구자(본인 등록 건).
- 증빙파일 상태가 계속 '변환중'이면 파일을 지우고 다시 올린다(보안·암호화 문서는 해제 후 등록).

## 연구비 이체 실행 방법
출처: 초보자용 매뉴얼 44·47쪽
- 이체 실행 조건 4가지: 개인공동인증서로 RCMS 로그인, 이체 권한 보유, 이체 비밀번호 입력, 법인범용공인인증서 인증.
- 방법: 연구비이체실행 화면에서 대상을 선택 → '연구비 이체 실행' → 이체 정보 확인 → 이체비밀번호 입력 후 '이체실행' → 기관 법인공동인증서로 인증.
- 이체 비밀번호는 이체 권한자(과제책임자, 이체권한을 부여받은 참여연구자·일반사용자)가 '이용환경설정 → 이체환경관리 → 이체비밀번호설정'에서 등록한다.

## 연구비 이체 결과 확인과 재실행
출처: 초보자용 매뉴얼 48~50쪽
- 연구비이체결과 화면에서 과제·조건을 선택해 조회한다. 증빙구분을 누르면 전자(세금)계산서·카드 매출전표·현금영수증을 확인할 수 있다.
- 확인 서류가 필요하면 대상 선택 후 '이체확인증'을 출력한다.
- 이체상태가 '집행(이체)오류'이면 '이체 재실행'으로 계좌정보를 수정(예금주 조회 후 '이체 재실행 등록')하고, 연구비이체실행 화면에서 다시 이체한다.

## 연구비 입금 전 집행 (자체 자금으로 먼저 지출)
출처: 숙련자용 매뉴얼 FAQ Q23(96쪽), 혁신법 매뉴얼 표 3-25(262쪽)
- 과제 시작일이 지났으나 정부지원금 입금이 늦어 잔액이 부족하면, 기관 자금으로 먼저 지출한 뒤 연구비가 입금되면 증빙 유형에 따라 연구비계좌이체 형태로 소급받을 수 있다.
- 전자세금계산서·현금영수증·기타 증빙: 연구비계좌이체 허용 항목은 그대로 연구비계좌이체, 비허용 항목은 사용 등록 시 '협약전사용금액' 사유를 선택한 뒤 연구비계좌이체.
- 카드 증빙: 사용 등록 시 기관의 카드결제계좌로 입금된다.
